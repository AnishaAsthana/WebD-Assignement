# WebD-Assignement
This repository contains a complete collection of 18 hands-on web development assignments built strictly using pure HTML5, progressing from core document structure, text formatting, semantic elements, and nested lists to hyperlinks, multimedia embeds, accessible layouts, complex data tables, and validated forms. 
The coursework culminates in a capstone mini-project: an Accessible Student Admission Page

Tools: VS Code, Git, and a web browser (Chrome, Edge or Firefox). Save each program as an .html file and open it in the browser. 

Contents
Assignment 1: HTML Page Structure and Comments
Assignment 2: Headings, Paragraphs, Formatting and Special Characters
Assignment 3: Block and Inline Elements
Assignment 4: Semantic and Non-Semantic Elements
Assignment 5: Unordered, Ordered and Description Lists
Assignment 6: Nested and Mixed Lists
Assignment 7: Navigation Menu Using Lists
Assignment 8: Hyperlinks and Images with Attributes
Assignment 9: Quotation and Citation Elements
Assignment 10: Multimedia: Image, Video, Audio and YouTube
Assignment 11: Accessibility
Assignment 12: Table with Headers, Caption and Footer
Assignment 13: Rowspan and Colspan (Timetable)
Assignment 14: Nested and Responsive Tables
Assignment 15: Form: Input Elements, Label and Fieldset
Assignment 16: Select, Textarea and Buttons
Assignment 17: Form Attributes and Input Validation
Assignment 18: Mini Project: Accessible Student Admission Page
